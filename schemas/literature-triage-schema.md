# Literature Triage Schema

Required: `LT-` ID, decision question, target IDs, paper/source IDs, required reading tier, threat/coverage role, expected information gain, access state, gate impact, budget/deadline, status, next action, debt IDs, and version.

Validity:

- Priority reflects decision value and uncertainty, not prestige, citations, or publication outcome.
- Only `FULL_TEXT_READY` can close an R2/R3/R4 requirement; every other access state remains unresolved for deep-reading closure.
- An inaccessible gate-critical source creates debt and caps the associated conclusion.
- Queue completion requires an explicit disposition of gate-critical items, not universal reading.
