# Research Forge Promotional Poster Design

## Deliverables

Create three raster assets using one visual system:

1. English README banner, 3:1 landscape.
2. Chinese README banner, 3:1 landscape.
3. Chinese social-post poster, 4:5 portrait.

## Message hierarchy

English banner:

- `Research Forge`
- `Adversarial research direction for AI & deep learning`
- `Search to reject · Hypothesis before architecture · Falsification before optimization`

Chinese banner:

- `Research Forge`
- `面向 AI 与深度学习的对抗式科研选题 Skill`
- `搜索以拒绝 · 假设先于架构 · 证伪先于优化`

Chinese post:

- `Research Forge`
- `别问想法听起来是否新颖，先尝试证明它并不新颖。`
- `文献攻击 · 机制假设 · 最低成本证伪 · 四个人工 Gate · Zotero/BibTeX 交付`

## Visual direction

Use a scientific editorial aesthetic fused with a forge workshop: deep navy field, orange-gold molten lines, evidence cards, paper fragments, linked nodes, and a luminous decision path. The main visual should suggest prior-art pressure being refined into a defensible research decision.

Use an expressive artistic display face for the `Research Forge` title and restrained sans-serif typography for supporting copy. Keep text as a separate precision overlay rather than relying on generated lettering. Preserve generous negative space, strong contrast, and legibility at README thumbnail size.

## Constraints

- Generate the abstract visual layer with the image-generation tool without embedded text.
- Overlay the exact approved copy locally so spelling and punctuation remain correct.
- Do not use unsupported claims such as “best”, “first”, or guaranteed novelty.
- Keep the three assets visually related but crop compositions for their target aspect ratios.
- Store final assets under the repository `assets/` directory and link them from both README files.
