# Exploration Mode Example

## Input

“Find a strong research direction for tiny-object end-to-end detection under a modest compute budget.”

## Correct Run Shape

1. S00 records `EXPLORATION`; “tiny-object assignment is the cause” remains `UNKNOWN`, not fact.
2. G1 locks task, end-to-end method scope, publication horizon, modest compute, accessible datasets, and search cutoff.
3. S02–S05 map data/representation/assignment/objective/inference/evaluation failures, research lines, paper families, and saturated generic module directions.
4. S06 produces 8–15 mechanism questions spanning several failure classes. No candidate is “YOLO + attention.”
5. S07/S08 kill candidates with mature direct solutions, no prediction, or obvious stitching; G2 sees both survivors and kills.
6. S09 searches exact, historical, neighboring, and recent collisions for selected finalists and verifies T4/T5 at R3/R4.
7. S10 writes killed claims and a qualified residual boundary. If no survivor remains, it rolls back to S06.
8. S11–S12 form and attack method-free hypotheses; G3 locks only a survivor with alternatives and falsifiers.
9. S13–S16 design diagnostics/cheap killers, audit resources, and run independent reviewer attacks.
10. S17 separates scientific decision from execution readiness; G4 alone permits S18.

## Evidence Discipline

The final dossier distinguishes directly measured facts, inferred failure classes, hypotheses, and unknowns. Search saturation qualifies scope; it never proves global firstness.
