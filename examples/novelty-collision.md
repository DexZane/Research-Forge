# Novelty Collision Example

## Situation

A candidate has passed G3—or even G4—when a recent preprint appears to test the same core hypothesis and mechanism.

## Correct Response

1. Set pending gate `EMERGENCY_NOVELTY_COLLISION`; freeze experiments/dossier work.
2. Register the preprint as a paper family; weak venue or missing citations do not make it irrelevant.
3. Upgrade from discovery to R3; inspect exact claims, formulation, mechanism, training/inference, experiments, supplement, and dates. Use R4 if official code decides equivalence.
4. Create evidence units and a dimension-level candidate threat. Keep `PRELIMINARY_T5` until formal conditions are met.
5. Propagate only after verification. Identify killed claims, surviving residual, affected hypotheses/experiments/reviewer reports, and stale reports.
6. Snapshot and present:
   - `LOCAL_DAMAGE`: bounded claim peeling; resume S10.
   - `MAJOR_REFRAME`: return S06/S10 and reopen search.
   - `FULL_COLLISION`: near-zero residual; recommend KILL at the gate.

## Integrity Rule

Prior G4 approval does not immunize the project. Sunk cost and author preference never reduce threat level.
