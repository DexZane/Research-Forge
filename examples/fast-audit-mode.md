# Fast Audit Mode Example

## Input

“Run a fast adversarial audit on my idea: replacing cross-attention with state-space models (Mamba) in diffusion image generation to achieve linear-time high-resolution sampling.”

## Correct Run Shape

- Recognize `FAST_AUDIT` mode at S00 Intake; decompose claimed symptom (quadratic attention cost), mechanism (long-range selective recurrent state compression), and target baseline (`BL-0001`: DiT-XL/2).
- Bypass S02–S08 wide candidate generation and red-ocean matrix build; immediately establish active innovation signature `IS-0001` and baseline delta statement.
- Execute fast adversarial novelty scan (S09): discover prior SSM-diffusion works (e.g., DiM, ZigMa, Mamba-Diff). Assign `T4` threat at `R3` depth.
- Perform innovation peeling (S10): kill the generic claim "first to apply SSM to diffusion"; isolate the residual gap (e.g., whether continuous bidirectional scanning avoids directional artifacts in latent patches).
- Formulate method-free hypothesis (S11/S12) and attack with alternatives (e.g., simple windowed attention, FlashAttention-3, or linear attention baselines).
- Design single cheapest killer probe (S14): pre-register an `F0`/`F1` state-reconstruction and latency-vs-FID benchmark test with a strict kill condition (if latency benefit disappears under FlashAttention-3 kernel baseline, KILL).
- Run rapid 3-reviewer vulnerability sweep (S16) and synthesize `reports/fast_audit_report.md`.
- Conclude with actionable triage verdict (`REFINE` or `KILL`) within 10–15 minutes of interactive time.

## Incorrect Behavior

- Endorsing the idea because "Mamba + Diffusion is trendy".
- Searching only for the exact repository name instead of the broader mechanism.
- Generating a full 18-state project workspace and demanding 4 slow human gates when a fast gut-check audit was requested.
- Skipping the cheapest killer probe pre-registration or failing to peel the already-published SSM diffusion prior art.
